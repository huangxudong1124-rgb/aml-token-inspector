Design System · WorkBuddy / CodeBuddy Skill

AML Design Token Inspector

把 AML Design 设计系统的全部设计 token 渲染成一个离线、双击即开的单文件 HTML 自检页， 涵盖 Color / Typography / Spacing / Border / Shadow / Radius 六大板块。点卡片即复制 CSS 声明。

在线看自检页 下载 skill 包

方式一 · 一条命令安装（推荐）

在终端粘贴执行，脚本会自动装到当前客户端的 skills 目录。

curl -fsSL ./install.sh | bash
WorkBuddy 装到 ~/.workbuddy/skills/，CodeBuddy 装到 ~/.codebuddy/skills/；装完需重启会话或刷新技能列表才会加载。

方式二 · 手动安装（最简单）

不习惯命令行？下载压缩包，解压后把文件夹拖进去就行。

  1. 点上方「下载 skill 包」，得到 skills.zip
  2. 解压，得到 aml-token-inspector 与 规范样式 两个文件夹
  3. 把它们复制到 ~/.workbuddy/skills/（访达中用 Shift+Cmd+G 输入路径跳转）
  4. 重启会话；只想看页面的话，直接双击 index.html 即可
