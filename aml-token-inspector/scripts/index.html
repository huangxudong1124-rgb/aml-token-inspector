间距 · Spacing

9 级间距尺度（4/8/12/16/20/24/32/40/48 px），按 rem 等比缩放。点击任意条目复制 gap / padding / margin 简写。

边框 · Border

分割线 / 描边样式，点击卡片复制 box-shadow（all 全边框 · top 上 · bottom 下 · left 左 · right 右）。

投影 · Shadow

点击卡片复制 box-shadow。按用途分组：卡片投影 / Icon / 弹窗浮层 / 按钮（黑·灰·紫），每组用一个代表色保持一致。

圆角 · Radius

点击卡片复制 border-radius。设计原则：内圆角统一 4 / 8px。
